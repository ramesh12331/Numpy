# 1️⃣ What is the Random Module?

NumPy provides random-number functionality through:

```python
np.random
```

Example:

```python
import numpy as np

print(np.random.rand())
```

Possible output:

```text
0.73642185
```

If you run it again, you may get:

```text
0.18372941
```

The value changes because it is generated randomly.

---

# ⭐ Important

Random numbers generated by computers are generally **pseudorandom**.

That means they are generated using an algorithm that produces values that **appear random**.

For most Data Science tasks, NumPy's random generators are very useful.

# 2️⃣ `np.random.rand()`

### 📖 Definition

`np.random.rand()` generates random floating-point numbers between:

```text
0 and 1
```

More precisely:

```text
[0, 1)
```

This means:

```text
0 → included
1 → excluded
```

---

# 🟢 Example 1

```python
import numpy as np

result = np.random.rand()

print(result)
```

Possible output:

```text
0.63829471
```

Every execution can produce a different value.

# ⭐ `rand()` vs `random()`

Both can generate random floating-point numbers between `0` and `1`.

### `rand()`

Uses dimensions as separate arguments:

```python
np.random.rand(2, 3)
```

### `random()`

Commonly uses a shape:

```python
np.random.random((2, 3))
```

Example:

```python
a = np.random.rand(2, 3)

b = np.random.random((2, 3))
```

Both produce a:

```text
2 × 3
```

array.

---

# 📊 Comparison

| Function        | Example     | Output        |
| --------------- | ----------- | ------------- |
| `rand()`        | `rand(5)`   | Random floats |
| `random()`      | `random(5)` | Random floats |
| `rand(2,3)`     | 2×3 array   | Random floats |
| `random((2,3))` | 2×3 array   | Random floats |

# 6️⃣ `np.random.randint()`

This is one of the **most useful random functions**.

### 📖 Definition

`np.random.randint()` generates random **integers** within a specified range.

### Syntax

```python
np.random.randint(low, high, size)
```

Important:

```text
low    → included
high   → excluded
```

---

# 🟢 Example

```python
import numpy as np

result = np.random.randint(1, 10, 5)

print(result)
```

Possible output:

```text
[3 8 1 6 4]
```

Every value is:

```text
>= 1
< 10
```

So possible values are:

```text
1 2 3 4 5 6 7 8 9
```

But never:

```text
10
```

---

# 🧠 Dry Run

```python

```

means:

```text
low  = 1
high = 10
size = 5
```

Therefore:

```text
Generate 5 random integers
from 1 through 9
```

# 9️⃣ `np.random.randn()`

Now we have another important function.

### 📖 Definition

`np.random.randn()` generates values from a **standard normal distribution**.

The standard normal distribution has approximately:

```text
mean = 0
standard deviation = 1
```

---

# 🟢 Example

```python
result = np.random.randn(5)

print(result)
```

Possible output:

```text
[-0.32  1.15 -0.48  0.73 -1.02]
```

Notice:

Values can be:

```text
negative
positive
near zero
```

Unlike `rand()`:

```text
rand() → 0 to 1
```

`randn()` can generate values outside that range.

---

# 🔥 `rand()` vs `randn()`

| Function  | Distribution    | Typical Range               |
| --------- | --------------- | --------------------------- |
| `rand()`  | Uniform         | `0 ≤ x < 1`                 |
| `randn()` | Standard normal | Can be negative or positive |

Visual idea:

```text
rand()

0 ─────────────── 1
```

while:

```text
randn()

negative ← 0 → positive
```

---

# 🔟 `randn()` 2D Array

```python

print(result)
```

Possible output:

```text
[[ 0.42 -1.21  0.63]
 [ 1.15  0.08 -0.72]]
```

Shape:

```text
(2, 3)
```

# 1️⃣1️⃣ `np.random.choice()`

### 📖 Definition

`np.random.choice()` randomly selects values from an array or sequence.

### Syntax

```python
np.random.choice(array, size)
```

---

# 🟢 Example

```python
import numpy as np

arr = np.array([10, 20, 30, 40, 50])

result = np.random.choice(arr)

print(result)
```

Possible output:

```text
30
```

Run again:

```text
50
```

The result can change.

---

# 1️⃣2️⃣ Choose Multiple Values

```python
arr = np.array([10, 20, 30, 40, 50])

result = np.random.choice(arr, size=3)

print(result)
```

Possible output:

```text
[20 50 10]
```

---

# 1️⃣3️⃣ Choice with Replacement

By default, `choice()` samples **with replacement**.

That means the same value can appear more than once.

Example:

```python
arr = np.array([10, 20, 30])

result = np.random.choice(arr, size=5)

print(result)
```

Possible output:

```text
[20 10 20 30 10]
```

Notice:

```text
20 → repeated
10 → repeated
```

---

# 1️⃣4️⃣ `replace=False`

If you don't want duplicates:

```python
arr = np.array([10, 20, 30, 40, 50])

result = np.random.choice(
    arr,
    size=3,
    replace=False
)

print(result)
```

Possible output:

```text
[40 10 30]
```

No value repeats.

### ⭐ Important

```text
replace=True
→ values can repeat

replace=False
→ values cannot repeat
```

# 1️⃣6️⃣ `np.random.seed()`

This is one of the **most important concepts** when working with random numbers.

### 📖 Definition

A **seed** makes random number generation **reproducible**.

In simple words:

> If you use the same seed and the same random-generation sequence, you can reproduce the same results.

---

# 🟢 Example

```python
import numpy as np

np.random.seed(42)

print(np.random.randint(1, 10, 5))
```

Output will be reproducible for that same setup.

If you run the same code again:

```python
np.random.seed(42)

print(np.random.randint(1, 10, 5))
```

you get the same sequence.

---

# 🧠 Why Do We Need Seed?

Suppose you are training a Machine Learning model.

You randomly split data:

```text
Dataset
   ↓
Random split
   ↓
Training data + Testing data
```

If the random selection changes every time, your experiment can become harder to reproduce.

Using:

```python
np.random.seed(42)
```

helps make the random process reproducible.

---

# ⭐ Memory Trick

```text
seed()
 ↓
Same starting point
 ↓
Same random sequence
```

Think of it like:

```text
🎲 Random generator
       ↓
    seed(42)
       ↓
 reproducible result
```

---

# 1️⃣7️⃣ Same Seed vs Different Seed

### Same seed

```python
np.random.seed(10)
print(np.random.randint(1, 100, 5))
```

Run the same code again with the same seed:

```python
np.random.seed(10)
print(np.random.randint(1, 100, 5))
```

You get the same sequence.

### Different seed

```python
np.random.seed(20)
```

The generated sequence will generally be different.

# 1️⃣8️⃣ Generate Random Float Between Custom Range

Suppose we want random values between:

```text
10 and 20
```

We can transform `rand()`:

```python
result = 10 + np.random.rand(5) * 10

print(result)
```

Possible output:

```text
[13.25 17.82 11.46 19.13 15.67]
```

### 🧠 Formula

```text
low + random × (high - low)
```

For:

```text
low = 10
high = 20
```

```text
10 + random × (20 - 10)
```

So:

```text
10 ≤ result < 20
```

# 1️⃣9️⃣ Random Distributions

A **distribution** describes how random values are spread.

You already learned:

### 🎲 Uniform distribution

Using:

```python
np.random.rand()
```

Conceptually:

```text
All values in the interval have equal probability density.
```

---

### 📊 Standard normal distribution

Using:

```python
np.random.randn()
```

Conceptually:

```text
             ▲
             │
          █████
       ███████████
    █████████████████
────────────────────────→
        values
```

The center is around:

```text
0
```

and values become less common farther from the center.

# ⚠️ Common Mistakes

## ❌ Mistake 1 — Forgetting that `high` is excluded

```python
np.random.randint(1, 10)
```

Possible values:

```text
1 2 3 4 5 6 7 8 9
```

Not:

```text
10
```

---

## ❌ Mistake 2 — Thinking `rand()` generates integers

```python
np.random.rand(5)
```

generates **floating-point numbers**.

Example:

```text
[0.25 0.81 0.43 0.17 0.92]
```

For integers use:

```python
np.random.randint()
```

---

## ❌ Mistake 3 — Confusing `rand()` and `randn()`

```text
rand()
→ values from 0 to 1

randn()
→ standard normal distribution
```

---

## ❌ Mistake 4 — Forgetting `replace=False`

If you need unique samples:

```python
np.random.choice(
    arr,
    size=5,
    replace=False
)
```

---

## ❌ Mistake 5 — Expecting random results to remain the same

Without a fixed seed:

```python
np.random.randint(1, 100, 5)
```

can produce different results on different runs.

For reproducibility:

```python
np.random.seed(42)
```

# 💼 Interview Questions

### Q1. What is NumPy's random module?

**Answer:**

`np.random` provides functions for generating random numbers, random samples, and random data.

---

### Q2. What does `np.random.rand()` generate?

**Answer:**

Random integers where the lower bound is included and the upper bound is excluded.

randn()
